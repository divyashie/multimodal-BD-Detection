# Methods Paper

This folder holds the working materials for the methods-focused paper that reframes the original `multimodal-BD-Detection` project as a cautionary example.

Contents:

- The working outline and draft of the paper (`outline.md`).
- Re-runs of the legacy pipeline with additional diagnostic experiments (`experiments/`).
- Generated figures and notebooks (`figures/`).

Target venues: JMIR Mental Health, ML4H workshop, CHIL. Draft status: in progress.
